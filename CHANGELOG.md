# Changelog

## 0.4.0a1

- Clarify the personal-agent vision, target developers and a fictional photo-clue/user-explanation walkthrough.
- Define a first useful-assistance trial and distinguish planned interpretation and preference learning from the implemented review/MCP foundation.
- Keep default English documentation, privacy boundaries and current validation claims aligned.
- Add a system Photos picker for up to five selected images, on-device Vision scene prompts and user-written explanations.
- Require explicit wording confirmation, invalidate it on edits and keep disclosure selection separate.
- Keep images, classifier labels, confidence and source handles out of exports; provide in-memory session clearing.
- Add the `personal_assistance` purpose and a fictional preference/café-work correction demo on the existing consent and MCP path.
- Add Swift reflection/metadata checks and native UI coverage; document what still needs device and real-user validation.

## 0.3.0a1

- Add a versioned phone export contract with strict field, size, lifetime and attribution validation.
- Add an iOS SwiftUI review/export component: no records selected by default, exact JSON review, optional coarse metadata and cloud access off by default.
- Provide a standalone fictional iPhone demo project generator without Photos permission.
- Add explicit desktop review, exact-file acknowledgment, a private MCP session and generated summary instructions.
- Require both phone and desktop opt-in for cloud-allowed sessions; document that host policy labels are not network enforcement.
- Add one-command fictional phone handoff, future-read revocation and transport checks.
- Put privacy boundaries in the README, dedicated privacy statement, phone UI and Agent instructions.

The current bridge transfers a reviewed file. Automatic USB scanning, live phone synchronization and production Atlas Memoir integration remain pending.

## 0.2.0a1

- Add a fictional three-year fixture generator with 16 drafts and eight retrieval scenarios.
- Implement one read-only MCP stdio tool using the official SDK 2.3.0.
- Bind files, purpose and audience in trusted local configuration; re-read approvals on each query.
- Exercise real client/server transport, strict arguments, stale drafts, expiry and same-connection revocation.
- Document three actual Codex host checks with fictional tool data: cited writing, insufficient evidence and revoked access.
- Add native product screenshots and a screenshot walkthrough using an isolated fictional harness.
- Require exact reviewed-media hashes and strip PNG metadata before publication.
- Add pinned GitHub Actions workflows for core and MCP checks and package installation metadata.
- Keep the default README entirely in English.

At this release, native selective export, a native Agent approval interface and model answer quality evaluation were pending. See 0.3.0a1 for the subsequent reusable phone component.
