# Report a problem without sharing your life records

For a reproducible functional bug, use [a GitHub bug report](https://github.com/niulengxiao/atlas-context/issues/new/choose). Include the relevant version, operating system, command, expected result and a minimal fictional example. Review pasted output for personal paths or records. An issue should be reproducible without your photo library or a real export.

For a suspected privacy or security problem, open the repository's [Security tab](https://github.com/niulengxiao/atlas-context/security) and choose **Report a vulnerability**. GitHub private vulnerability reporting is enabled. Start with the affected component, a description of the boundary you believe failed and steps using invented data. Do not include real photos, phone exports, credentials or private runtime files, even in the initial private report. The maintainer can discuss a minimal reproduction there.

For ordinary contributions, see [CONTRIBUTING.md](../CONTRIBUTING.md). For product behavior and known limits, see [PRIVACY.md](../PRIVACY.md) and [validation scope](evidence.md). The project has no promised response deadline or bug bounty. The maintainer reviews reports as availability allows.
